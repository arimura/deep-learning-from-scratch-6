# Byte Pair Encoding

## BPE train
BPE学習用モジュールは以下の処理から構成される

- count pairs
  - 引数のトークンID配列で隣接するidのペアの出現回数をカウントする
  - dictionaryとして結果を返す
- merge
  - 指定されたペアを新しいトークンIDに置き換える
  - 引数にはトークンID配列、置き換えるペア、新しいトークンID、をとる
  - mergeされたトークンIDの配列を返す
- train bpe
  - 引数に対象文字列とボキャブラリーサイズを取る
  - 初期値は256なので、引数のボキャブラリーサイズとの差からマージ回数を計算
  - マージ回数分の繰り返し処理で以下を実行
    - 隣接ペアの統計を count pairs で取得
    - 最頻出ペアを選択
    - 新しいトークンIDを256以降から連番割り当て
    - マージ実行
  - ID配列、マージルール配列を返す
- BPE tokenizer
  - 初期化
    - 引数: マージルール配列
    - IDからバイト列の対応表を作る
      - 0-255は普通に作る
      - 256以降はマージルールから作る
    - 語彙サイズを設定する 
  - encode
    - 引数: エンコード対象テキスト
    - マージルール配列をループして、merge処理を実行する
    - mergeしたトークンID配列を返す
  - decode
    - 引数: トークンID配列
    - トークンIDをループして、IDからバイト列の対応表からバイト列を生成
    - 全てのバイト列を連結して、utf-8のテキストに変換して返す
