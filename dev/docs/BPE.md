# Byte Pair Encoding

## BPE train
BPE学習用モジュールは以下の処理から構成される

- count pairs
  - 引数
    - ids: トークンID配列
    - counts: ハッシュテーブル 
  - トークンID配列の隣接するidのペアの出現回数をカウントする
    - 引数のcountsが存在する場合は、それを更新する
  - ハッシュテーブルてして結果を返す
- merge
  - 指定されたペアを新しいトークンIDに置き換える
  - 引数にはトークンID配列、置き換えるペア、新しいトークンID、をとる
  - mergeされたトークンIDの配列を返す
- train bpe
  - 引数
    - 対象文字列
    - ボキャブラリーサイズ
    - 特殊トークン、デフォルトは`<|endoftext|>`
  - 特殊トークンで対象文字列を配列に分割し、トークンID配列の配列に変換
  - 初期値は256なので、引数のボキャブラリーサイズとの差からマージ回数を計算
    - 固定特殊トークンように1追加
  - マージ回数分の繰り返し処理で以下を実行
  　- 空のカウント用ハッシュテーブルを宣言
    - 隣接ペアの統計を count pairs で取得（空のカウント用を引数にする）
    - ペアが存在しない場合は繰り返し終了
    - 最頻出ペアを選択
    - 新しいトークンIDを256以降から連番割り当て
    - トークンID配列の配列全体に対してマージ実行
  - ID配列、マージルール配列を返す
- BPE tokenizer
  - 初期化
    - 引数: マージルール配列
    - IDからバイト列の対応表を作る
      - 0-255は普通に作る
      - 256以降はマージルールから作る
    - 語彙サイズを設定する 
  - encode
    - 引数: エンコード対象テキスト
    - マージルール配列をループして、merge処理を実行する
    - mergeしたトークンID配列を返す
  - decode
    - 引数: トークンID配列
    - トークンIDをループして、IDからバイト列の対応表からバイト列を生成
    - 全てのバイト列を連結して、utf-8のテキストに変換して返す
